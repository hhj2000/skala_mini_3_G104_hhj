# 지원 언어 목록과 실제 지원 범위

2026-10-21 기준 **한국어 이름이 등록된 자연어 229개**를 지원 언어 선택 목록으로 제공합니다. 베트남어·슬로베니아어·고대 교회 슬라브어가 포함됩니다. 기존 7,737개 코드 목록에서 한국어 이름이 없는 항목을 제외했으며, 화면과 API는 남은 전체 229개를 지원 언어 수로 표시합니다.

## 사이트에서 사용

1. 왼쪽 메뉴 **언어 목록**을 누릅니다. 전체 목록은 한국어 이름의 **가나다순**이며 48개씩 표시합니다. 검색 결과에도 같은 정렬을 적용합니다.
2. 한국어/영어 이름이나 코드로 검색합니다. 예: `베트남어`, `슬로베니아어`, `고대 교회 슬라브어`, `Finnish`, `he`.
3. 현대·고전·사멸 분류와 **사전 자료 등록 항목만** 필터를 사용할 수 있습니다. 데스크톱에서 검색 입력·분류 선택·사전 체크박스·갱신 버튼은 같은 높이로 정렬되며 좁은 화면에서는 줄바꿈됩니다.
4. **이 언어로 만들기**를 누르면 선택한 언어로 창작 화면에 돌아옵니다. 기존 효과·제약은 유지됩니다.

채팅으로 언어를 입력하는 방식도 유지합니다. 목록 밖 자유 입력이나 이미 저장된 주문은 자동 삭제하지 않습니다. 목록에서 제외된 언어는 지원 수에 포함하지 않으며, 사용자 인공 언어는 별도의 직접 정의 기능으로 유지합니다.

## 선정 기준과 고정 목록

- `kharakteres/data/korean-language-names.json`: 한국어 표시 이름이 있는 **229개 코드와 이름**. 기존 기본 목록의 한국어 이름과 포함 WiktAPI 자료에서 이미 사용하던 한글 이름을 추출해 고정했습니다. 새 번역을 모델로 임의 생성하지 않았습니다.
- ISO 유형 L(현대), A(고대), H(역사), E(사멸)과 대조하고 인공어·특수/미식별 코드·수어를 음성 주문 목록에서 제외합니다. 수어의 자연어 여부를 판단한 것이 아니라 현재 음성 주문 흐름의 범위를 정한 것입니다.
- 서버와 Docker가 같은 포함 파일을 읽습니다. 서버 시작에 외부 연결은 필요하지 않습니다.
- **사전 목록 갱신은 제공자 등록 상태만 갱신합니다.** 한글 이름·지원 범위·가나다순은 바뀌지 않으므로 영어 이름만 있는 수천 항목이 다시 추가되지 않습니다. 이전 캐시가 남아 있어도 같은 제한을 적용합니다.
- `language_defaults.py`의 과거 13개 목록은 호환 별칭·사전 섹션·모델 후보 구성용 내부 자료입니다. 사용자에게 표시하는 지원 언어 수는 229개이며 API의 `languages`도 전체 229개를 반환합니다.

화면 분류는 **현대 언어·고전 언어·사멸 언어**입니다. ISO A(고대)와 H(역사)를 고전 언어로 통합합니다. API `family=C`가 두 유형을 함께 검색하며 기존 A/H 요청도 호환됩니다. 포함 목록은 현대 209개·고전 17개·사멸 3개입니다.

가나다순은 NFC 한글 이름 기준으로 정렬하며 기본 언어 우선이나 검색 정확 일치 우선 순서를 섞지 않습니다. 이름이 같으면 코드로 순서를 고정합니다.

## 사전 연결과 품질의 구분

포함 자료 기준 229개 모두 WiktAPI의 여러 판을 합친 언어 목록과 연결됩니다. 이는 영어판에 특정 단어가 있거나 전체 주문 문장이 검증됐다는 뜻이 아닙니다. 조회 결과의 실제 `lang_code`를 대조하며, 정확한 원 사전 섹션 이름을 확인하지 않은 언어는 실제 API 응답 링크를 제공합니다. [출처 범위](WEB_SOURCES.md)를 참고하세요.

**229개는 선택 가능한 지원 언어 수이며, 모든 언어의 번역·문법·한글 발음·IPA 품질 통과 수가 아닙니다.** 희귀 언어와 고전어의 품질은 모델별로 다르며 검수가 필요합니다. STT/TTS의 지원 범위와 발음 정확도 역시 별도입니다. fake 모드는 실제 번역을 하지 않습니다.

고대 교회 슬라브어의 키릴/고대 키릴·글라골 문자 검사는 유지합니다. 문자 검사가 현대 러시아어와 고대 언어를 정확히 구분하는 감별기는 아닙니다. 사용자 편집·전문 검수와 단어 출처 발견을 구분합니다.

## 자료와 API

ISO 원본은 [pycountry가 배포하는 Debian iso-codes](https://github.com/pycountry/pycountry), 사전 목록 원본은 [WiktAPI](https://wiktapi.dev/quickstart)입니다. 원본 ISO/사전 자료는 정규화·출처 재현용으로 포함하지만 화면에는 고정 한국어 목록만 노출합니다. 원본 URL·해시와 파생 목록 해시는 `kharakteres/data/language-data-sources.json`, 라이선스와 선정 기준은 [데이터 안내](../kharakteres/data/README.md)에 기록합니다.

인증 후 API를 사용합니다.

- `GET /api/catalog`: `languages` 229개·`registered_language_count` 229·전체 명칭 라벨·사전 상태.
- `GET /api/languages?q=베트남어&family=L&dictionary_only=true&offset=0&limit=48`: 가나다순 검색/분류. limit 최대 200.
- `POST /api/languages/refresh`: 사전 등록 상태만 갱신. 실패하면 기존 목록과 상태를 유지.

로컬 캐시는 `data/language_catalog.json`, Docker는 `/app/data/language_catalog.json`이며 `SPELL_LANGUAGE_CATALOG_CACHE`로 바꿀 수 있습니다. 갱신은 1분 간격이며 429/503 Retry-After를 존중하고 403은 프로세스의 추가 조회를 중단합니다. 읽기 전용 환경에서는 포함 목록·메모리 결과를 사용할 수 있습니다. 캐시에 사용자 주문 본문은 저장하지 않습니다.

모델 후보는 기존 핵심 언어와 검색 관련 후보 최대 25개만 전달하며 전체 229개를 매번 프롬프트에 넣지 않습니다. 후보는 사용자 데이터로 전달합니다.

## 검증과 적용

현재 전체 자동 테스트 **152개 통과**, SSE 클라이언트 **5개 통과**. 한국어 이름만 노출, 전체 229개·중복 없음·가나다순·분류/페이지·갱신 후 범위 유지·이전 캐시 호환·접근 거절·Retry-After·저장/재조회·모델 후보 한도를 확인합니다.

로컬과 read-only Docker의 임시 저장소에서 언어 수·가나다순·데스크톱 컨트롤 높이 정렬·모바일 가로 넘침 없음·검색 후 생성 화면 연결을 검증합니다. 포르투갈어·핀란드어·히브리어의 실제 사전 조회와 저장도 포함합니다. 이전 실제 OpenAI 3언어 생성 실험과 고정 데이터 정량 결과는 당시 실행의 증거로 보존하며, 이번 목록 축소로 전 언어의 생성 품질을 재평가했다고 주장하지 않습니다.
